ПЕРЕДАЧА МАРКЕТИНГА — iHub Admissions

Открывать: index.html (двойным кликом)

Структура:
  index.html        — обложка и первая секция
  pages/            — остальные страницы документа
  assets/style.css  — дизайн всех страниц (правится один раз)
  assets/nav.js     — боковое меню и кнопки «назад/дальше» (правится один раз)
  files/docs        — документы и таблицы
  files/screenshots — скриншоты интерфейсов
  files/logos       — логотипы сервисов
  files/templates   — шаблоны отчётов и планов

Важно: папку держать целиком. Отдельный html без assets и files работать не будет.
